# SSH Keychain 0.1.0

Initial public release.

## Highlights

- **Dynamic SSH key serving** via SSH agent protocol - no plaintext private keys in `~/.ssh/`
- **Five backends**: macOS Keychain (Mode A generic-password, Mode B Secure Enclave), plain files, HashiCorp Vault, 1Password (`op` CLI), 1Password OPVault
- **Four integration modes**: long-lived daemon agent, `--once` short-lived agent, `load` (push into existing `$SSH_AUTH_SOCK`), `run` (wrap any command with an ephemeral agent)
- **macOS app** with menu bar, Settings tabs, Activity log, and a first-launch onboarding wizard
- **Sparkle 2** integration for in-app updates

## Known limitations

- Secure-Enclave key generation requires this Developer-ID-signed build (ad-hoc-signed builds can't persist `SecKey` references)
- HashiCorp Vault OIDC auth lands in v1.1; v0.1 supports static-token auth only
- Encrypted-PEM key import is deferred to a follow-up

## Compatibility

- macOS 14.0 (Sonoma) or later
- Apple Silicon required for Secure Enclave key generation
- Intel Macs can use all other backends and integration modes
